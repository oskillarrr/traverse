# Rule packs

Optional rule files with knowledge that belongs to one country, sector or organization. The core
catalog embedded in Traverse stays agnostic; a pack is loaded only when asked for:

```sh
traverse scan --rules rulepacks/es-public-sector.json --out reports app/
```

or with `"rules": ["path/to/pack.json"]` in `traverse.json`.

| Pack | Scope |
|---|---|
| `es-public-sector.json` | Spanish public sector: @firma/AutoFirma, Cl@ve, FIRe, Valida, FNMT/CERES (`ES-*`) |

Conventions: ids prefixed with the scope so they never override a core rule, a `version` named
after the pack, examples for every rule (`traverse rules test --rules <pack>`). Packs are
generated by `tools/genrules.py` and checked by `internal/rules/packs_test.go`.
